AI Disclosure

This project was developed with the assistance of artificial intelligence (AI) tools.

How AI was used

AI was used as an assistant in the following areas:

Development: help with writing, refactoring and explaining code.
Testing: help with writing and improving tests, and with debugging.
CI: help with setting up and maintaining continuous integration workflows.
Packaging: help with the Flatpak manifests, the RPM and DEB recipes and the workflows that build GitHub releases. The
manifest for Flathub is written by a person, without AI assistance.
Documentation: help with writing the project's documentation, such as the README, the contributor and security
guides, the runbooks and the release notes.
Automation: AI agents (Claude Code in CI, and Hive once the maintainer connects it) may open issues and pull requests
on their own. They follow AGENTS.md and cannot push to main. Low- and medium-risk pull requests can be merged by the
merge queue once every check passes; high-risk changes (workflows, build and packaging files, agent instructions)
wait for the maintainer's review.
Responsibility

AI was used as a supporting tool. The maintainer remains responsible for the contents of this repository.

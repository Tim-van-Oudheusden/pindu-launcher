# Translating

Pindu launcher uses gettext. Translators work on [Weblate](https://weblate.org/); this file says how the repository is
laid out for it, and which settings the Weblate project needs. Setting up that project is the maintainer's step (#60).
Until it exists, send a translation as an ordinary pull request (see [Without Weblate](#without-weblate)).

## The repository side

| File | Role |
| --- | --- |
| `po/pindu-launcher.pot` | The template: every translatable string in the code, Blueprint files, desktop file, MetaInfo and GSettings schema. Committed, so Weblate reads it straight from `main` |
| `po/*.po` | One translation per language, named by its POSIX language code (`nl.po`, `pt_BR.po`) |
| `po/LINGUAS` | The languages Meson builds, one code per line. Empty until the first translation lands; a `.po` file that is not listed here is not installed |
| `po/POTFILES.in` | The files xgettext reads. The `check-potfiles` Meson test fails when a file with translatable strings is missing from it |
| `po/check-pot.sh` | Run by CI after `meson test`; fails when the committed template's strings differ from the code's. Source locations and the creation date are ignored |

The template belongs to the repository: whoever changes a translatable string refreshes it in the same pull request with
`meson compile -C _build pindu-launcher-pot`, and CI enforces that. Weblate only reads the template and never writes
it.

## Weblate settings

These match the [Weblate documentation](https://docs.weblate.org/en/latest/admin/projects.html) as of Weblate 2026.11.
Weblate keeps its configuration on the server; there is no repository file that sets up a project or component. (A
`.weblate` file is only read by the [`wlc` command-line client](https://docs.weblate.org/en/latest/wlc.html) to pick a
server and component, so the repository does not have one.)

### Project

| Setting | Value |
| --- | --- |
| Project website | `https://github.com/Tim-van-Oudheusden/pindu-launcher` |
| Translation license | GNU General Public License v3.0 or later (`GPL-3.0-or-later`), the app's licence |
| Language code style | Default based on the file format (POSIX for gettext, for example `pt_BR`) |

### Component

Create one component, preferably from the Hosted Weblate GitHub App ("Connect GitHub account"), which gives Weblate
access to clone the repository, open pull requests and receive push notifications without a separate webhook.

| Setting | Value |
| --- | --- |
| Source code repository | `https://github.com/Tim-van-Oudheusden/pindu-launcher.git` |
| Repository branch | `main` |
| Version control system | GitHub pull requests |
| Repository push URL | empty (Weblate opens pull requests from its fork) |
| Push branch | empty |
| File format | gettext PO file |
| File mask | `po/*.po` |
| Monolingual base language file | empty (PO is bilingual) |
| Template for new translations | `po/pindu-launcher.pot` |
| Language filter | default (`^[^.]+$`) |
| Source language | English |
| Language code style | Default based on the file format (inherit from the project) |
| Adding new translation | Create new language file |
| Manage strings | off: strings come from the code through the template, so strings added on Weblate would be lost |
| Push on commit | on, so each batch of translations becomes a pull request |
| Push on update | off if Weblate's pull requests are squash-merged, so upstream changes alone do not start CI runs |
| Lock on error | on |

Weblate's built-in commit messages follow Conventional Commits, which matches the rest of the history.

Translations never go straight to `main`: Weblate's pull requests pass the same CI and review as any other.

### Add-ons

| Add-on | ID | Why |
| --- | --- | --- |
| Update LINGUAS file | `weblate.gettext.linguas` | Adds a new language to `po/LINGUAS` in the same commit as its `.po` file, so Meson builds and installs it |
| Update PO files to match POT (msgmerge) | `weblate.gettext.msgmerge` | Merges template changes from `main` into every `.po` file, so new strings show up and changed ones are marked for review |
| Squash Git commits (optional) | `weblate.git.squash` | Keeps a translation pull request to one commit. Choose "All commits into one" with "Append trailers", so every translator is credited with a `Co-authored-by:` line |

Do not install "Update POT file (Meson)" (`weblate.gettext.meson`): the template is generated by the project's own
Meson build and checked by CI, and a second generator on Weblate would fight with it.

## Without Weblate

Configure a build folder once (`meson setup _build`), then, for Dutch:

```sh
msginit --locale=nl --input=po/pindu-launcher.pot --output-file=po/nl.po
echo nl >> po/LINGUAS
```

Translate `po/nl.po`, check it with `msgfmt --check --output-file=/dev/null po/nl.po`, and try it in a build with
`LANGUAGE=nl`. When the template has changed since, `meson compile -C _build pindu-launcher-update-po` merges the new
strings into every `.po` file.
